A one-page newspaper front page summing up Tuesday 17 November 2026's world news: the Crimea bridge struck again, tankers mined off Hormuz, the first Xi–Trump–Putin summit confirmed, a third US carrier in the Gulf, the AI-chip loophole closed, and the US losing measles-free status. `draw_frontpage.py` draws the page from the day's verified headlines; `main.py` (Python 3.13, standard library only) copies the finished `entry.png` to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
